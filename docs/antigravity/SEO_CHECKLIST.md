## 2. Structured Data (JSON-LD) Implementation & Compliance

All structured data schemas are strongly typed and adhere strictly to Google's Structured Data Guidelines and the project's **Content Status Rule**:

1. **`Organization` Schema (`src/lib/seo/jsonld.ts`)**:
   - `name`: `CODESYNC Digi Marketing Pvt. Ltd.`
   - `legalName`: `Codesync Digi Marketing (OPC) Pvt Ltd`
   - `url`: `https://www.cdmlko.com`
   - `contactPoint`: Customer support phone (`+91 8948040913`), available in English & Hindi, India area.
   - **Omission by Design:** Zero unconfirmed `sameAs` social links (avoiding crawl penalties for unverified profiles).

2. **`ProfessionalService` / `LocalBusiness` Schema (`src/lib/seo/jsonld.ts`)**:
   - `name`, `legalName`, `telephone`, `email`, `priceRange: "$$"`.
   - `address`: City-level address (`Lucknow, Uttar Pradesh, IN`).
   - `areaServed`: Lucknow, Uttar Pradesh.
   - **Omission by Design:** Exact street address is omitted because legacy records had contradictory addresses; city-level is accurate and verified.
   - **CRITICAL Omission by Design:** **NO `Review` or `AggregateRating` schema** is rendered. The 5.0/86 review metric mentioned in legacy marketing material was unverified per client dossier, so schema review flags are omitted to prevent Google manual action penalties.

3. **`Service` Schema**:
   - Rendered on every `/services/[slug]` route.
   - Connects provider, area served, terms/privacy URL, service description, and canonical URL.

4. **`BreadcrumbList` Schema**:
   - Implemented across all public pages.
   - Conforms to standard hierarchy: `Home (1) > Parent (2) > Child (3)`.

5. **`FAQPage` Schema**:
   - Emitted only for actual verified FAQ questions rendered on the corresponding page (`/`, `/pricing`, `/contact`, `/services/[slug]`).

6. **XSS Protection**:
   - Rendered using `src/components/seo/JsonLd.tsx`, escaping all `<` occurrences to `\u003c` to avoid script breakout vulnerabilities.
